### Competition Submission Guidelines
#### 1. Reference Example
Teams can refer to the file structure under the "Reference Example" directory for submission format. The submission must include the following files:
- Introduction to the Agent scenario and technical solution，it can be in English or Chinese.
- Agent code, which must include a necessary README file to ensure the code is runnable
- Agent Demo, which can be presented in the form of a screen recording showing the Agent's operation process
The above three parts are mandatory, but the code structure and document format are for reference only and are not restricted.
#### 2. Submission Format
Teams should submit their entries in the [Competition Submission] folder.
The naming convention should be: Team Name + Agent Name + Team Leader's Employee ID
