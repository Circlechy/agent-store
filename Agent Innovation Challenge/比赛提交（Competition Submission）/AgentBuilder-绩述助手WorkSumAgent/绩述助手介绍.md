# 绩述助手 (WorkSum Agent)

## 1. Agent应用场景

### 场景概述

绩述助手（WorkSum Agent）是一个智能工作总结助手，帮助职场人士从繁杂的日常材料（文本、文档、图片甚至直接通过自动截图）中自动抽取工作事项，并根据需求撰写各类工作报告，满足工作中日报、周报、月报甚至是年度绩效个人总结的需求。

在日常工作中，我们经常需要：
- 从会议记录、邮件、文档中提取工作内容
- 整理截图中的工作信息
- 汇总多天的工作记录生成报告
- 撰写各种格式的工作总结

绩述助手通过AI技术，将这些繁琐的工作自动化，让用户专注于核心业务，告别"写报告"的烦恼。

### 典型用户场景

1. **忙碌的研发工程师**：张工每天需要处理大量代码、文档和会议记录，经常忘记记录工作内容。他开启自动截图功能，系统每5分钟自动截图并识别工作内容，下班时一键生成日报，轻松完成工作记录。

2. **项目管理者**：李经理需要每周汇总团队的工作进展。她将本周的会议纪要、项目文档、进度截图上传到系统，系统自动提取关键信息并生成结构化的周报，大大节省了整理时间。

3. **销售代表**：王销售经常在外拜访客户，通过手机拍照记录客户沟通内容。回到办公室后，将照片上传到系统，AI自动识别并提取客户需求、跟进事项等信息，自动生成客户跟进报告。

4. **年度绩效总结**：赵主管需要在年底撰写年度工作总结。她选择日期范围（全年），系统自动汇总所有工作记录，智能分析并生成结构化的年度绩效报告，包含主要项目、成果、问题和来年计划。

5. **混合输入场景**：陈设计师同时上传了设计稿截图、项目需求文档和文字说明，系统自动合并分析，提取设计任务、完成内容、遇到的问题和下一步计划，生成完整的工作记录。

### 核心技术组件

#### 2.1 多模态内容提取技术

**技术特点**：
- **文本提取**：直接处理用户输入的文本内容
- **文档解析**：支持PDF、Word、TXT、MD、JSON等多种格式，自动提取文档中的文本内容
- **图片识别**：双模式处理
  - **OCR模式**：使用PaddleOCR进行文字识别，适合文字较多的截图
  - **多模态模式**：使用视觉大模型（如qwen3-vl-plus）进行内容理解，不仅能识别文字，还能理解图片语义
- **混合输入**：支持同时输入文字、文档、图片，通过TextMerger组件自动合并分析

**应用场景**：
- 从会议截图、文档、聊天记录中提取工作信息
- 识别设计稿、流程图中的工作内容
- 处理包含文字和图片的混合材料

#### 2.2 智能内容分析技术

**技术特点**：
- **基于LLM的结构化提取**：使用大语言模型（如deepseek-v3.2-exp）分析文本内容
- **多维度信息提取**：自动识别并提取以下信息：
  - **任务/项目**：主要工作任务或项目名称
  - **工作内容**：完成的具体工作描述
  - **成果**：取得的成果、进展或成就
  - **问题**：遇到的问题、挑战或困难
  - **下一步计划**：待办事项或行动计划
- **上下文理解**：能够理解工作内容的上下文关系，准确分类信息
- **自适应Prompt**：针对自动截图和用户上传使用不同的分析策略

**应用场景**：
- 从杂乱的工作记录中提取结构化信息
- 识别工作内容的类型（自有工作、会议、学习等）
- 自动分类任务、成果、问题等信息

#### 2.3 智能记录整合技术

**技术特点**：
- **时间窗口合并**：自动检测时间窗口内（默认30秒）的相似记录，避免重复
- **内容相似度分析**：基于任务主题相似度判断是否合并记录
- **LLM辅助整合**：使用大语言模型分析多条记录，智能合并相似内容
- **增量更新**：支持增量添加工作内容，自动合并到现有记录

**应用场景**：
- 避免短时间内重复提交相同内容
- 整合一天内分散的工作记录
- 合并相似的工作任务描述

#### 2.4 自动截图与队列处理技术

**技术特点**：
- **手动截图**：用户主动触发截图，立即分析
- **自动定时截图**：可配置截图间隔（默认5秒），自动捕获屏幕内容
- **异步队列处理**：使用异步队列处理截图任务，避免阻塞主流程
- **智能识别**：自动识别截图中的工作内容，区分工作相关和无关内容
- **差异检测**：可选开启差异检测，只处理有变化的截图

**应用场景**：
- 自动记录编程、设计等工作过程
- 捕获会议、讨论中的重要信息
- 记录工作状态变化

#### 2.5 智能报告生成技术

**技术特点**：
- **多时间维度汇总**：支持单日、日期范围（周报、月报、年报）汇总
- **LLM智能汇总**：使用大语言模型分析多条记录，生成结构化的汇总报告
- **信息聚类**：自动聚类相似任务，去重并保留主要项目
- **结构化输出**：生成包含任务、工作内容、成果、问题、下一步计划的结构化报告
- **格式化展示**：支持多种格式的报告输出

**应用场景**：
- 生成日报、周报、月报
- 撰写年度绩效总结
- 项目阶段总结报告

#### 2.6 工作流编排架构

**技术特点**：
- **基于openJiuwen WorkflowAgent**：使用工作流编排实现模块化设计
- **双工作流设计**：
  - **内容录入工作流**：处理输入→提取→分析→保存的完整流程
  - **报告生成工作流**：处理查询→格式化→汇总→输出的完整流程
- **组件化设计**：每个功能模块独立封装，便于维护和扩展
- **向后兼容**：通过适配器模式保持API兼容性

**技术优势**：
- 模块化设计，易于扩展新功能
- 工作流可视化，便于调试和优化
- 支持并行处理，提高效率

## 3. 技术亮点

### 3.1 多模态融合处理
- 支持文本、文档、图片的混合输入
- OCR和多模态模型双模式处理，适应不同场景
- 自动合并多种输入源，形成完整的工作记录

### 3.2 智能化程度高
- 基于大语言模型的深度理解，而非简单的关键词匹配
- 自动识别工作内容类型和关键信息
- 智能合并相似记录，避免冗余

### 3.3 用户体验优化
- 自动截图功能，无需手动记录
- Web界面友好，操作简单
- 支持批量处理和增量更新

### 3.4 可扩展性强
- 基于工作流架构，易于添加新功能
- 组件化设计，便于定制和优化
- 支持多种文档格式和图片处理方式

## 4. 应用价值

### 4.1 提升工作效率
- **节省时间**：自动提取和分析工作内容，节省80%以上的记录整理时间
- **减少遗漏**：自动截图功能确保重要工作内容不被遗漏
- **快速生成报告**：一键生成各类工作报告，告别"写报告"的烦恼

### 4.2 提高工作质量
- **结构化记录**：自动提取任务、成果、问题等结构化信息
- **智能汇总**：基于AI的智能汇总，生成高质量的工作报告
- **历史追溯**：完整的工作记录，便于回顾和总结

### 4.3 适应多种场景
- **个人工作记录**：适合个人日常工作总结
- **团队协作**：支持团队工作内容汇总
- **绩效评估**：为年度绩效评估提供数据支持
