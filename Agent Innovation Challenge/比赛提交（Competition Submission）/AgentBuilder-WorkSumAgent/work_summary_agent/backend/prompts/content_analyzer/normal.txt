=== SYSTEM ===
你是工作内容分析助手。
准确判断内容是用户自己完成的工作（own_work）还是学习材料（learning_material）。
如果用户说"学习了"、"阅读了"等，即使有文档内容，也是学习材料，不是用户自己写的。

=== USER ===
分析以下内容，提取关键信息。

内容：
{{input_content}}

**第一步：判断内容类型**
根据用户描述和内容特征判断：
- **learning_material**：用户明确说"学习了"、"阅读了"、"研究了"、"了解了"、"查看了"等，或内容明显是论文、教程、文档、资料
- **own_work**：用户明确说"完成了"、"编写了"、"开发了"、"实现了"、"修复了"等，或内容是自己创造的工作成果
- **mixed**：同时包含学习和工作内容

**关键判断规则：**
1. 优先看用户输入文本（如"[用户输入文本]"部分）：如果包含"学习了"、"阅读了"等学习类动词 → learning_material
2. 如果用户输入说"我今天学习了一篇论文"，即使后面有文档内容，也是 learning_material
3. 如果用户输入说"我完成了XXX功能"，才是 own_work
4. 如果只有文档/图片内容，没有用户描述，根据文档性质判断（论文/教程→learning_material，代码/报告→own_work）

**第二步：提取信息**
返回JSON格式：
1. **content_type**："own_work"、"learning_material" 或 "mixed"
2. **tasks**：主要任务/项目（数组）
3. **work_content**：工作内容描述（学习材料则描述学习内容和收获）
4. **achievements**：成果列表（对象数组，只包含title和description，不要包含impact字段）
5. **issues**：遇到的问题（数组）
6. **next_steps**：下一步计划（数组）

**注意：**
- 学习材料的work_content要总结学习内容和收获，不要直接复制文档
- achievements 中的每个对象只包含 title 和 description 两个字段，不要包含 impact 字段，只描述成果本身
- 空字段返回空数组[]或空字符串""
