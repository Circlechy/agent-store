# Browser Pilot

**Browser Pilot** 是一款基于 [OpenJiuwen Agent Framework](https://gitcode.com/openJiuwen/agent-core) 构建的**浏览器智能助手插件**。它不仅具备对网页内容的深度理解能力，还能够结合用户意图进行推理、规划与执行，作为真正的 AI 助手，自动完成多步骤、跨页面的复杂任务。

## 1. Agent应用场景

### 场景概述

Browser Pilot 是一个浏览器级 AI 助手，能够理解网页语义、执行复杂任务、自动决策与行动。它的核心理念是：**告诉它你想做什么，它会自己思考、执行、甚至从失败中学习。**

### 典型用户场景

#### 场景一：视觉问答 (VQA)

让 AI 看懂你看到的一切：
- **网页问答**：打开任意网页，直接向 AI 提问页面内容
- **截图识别**：框选屏幕任意区域，AI 根据图像内容回答
- **Deep Search**：复杂问题自动拆解，多轮搜索，深度汇总

#### 场景二：智能办公

把重复劳动交给 AI：
- **邮件处理**：阅读邮件内容，理解上下文，自动撰写专业回复
- **Excel 处理**：数据清洗、公式计算、图表生成、报表导出
- **表单填写**：智能识别字段，自动填充并提交

#### 场景三：长时程复杂任务

跨应用、多步骤，一气呵成：
- **场景示例**：观看美食视频/文章 → 提取食材清单 → 打开购物软件 → 自动加入购物车
- **工作流编排**：自动规划任务步骤，按序执行，异常处理
- **跨平台协同**：浏览器、本地应用无缝衔接

#### 场景四：功能自演进

越用越聪明的 AI：
- **失败反思**：任务失败时自动分析原因
- **上下文学习**：基于历史交互优化执行策略
- **自主修正**：调整方案后重新执行，直到成功

Browser Pilot 由**浏览器插件（前端）** 和 **Agent 服务（后端）** 两部分组成。

### 核心技术组件

#### 2.1 SuperReAct 增强推理循环

SuperReAct 是增强版的 ReAct (Reasoning + Acting) 框架，实现思考 → 行动 → 观察的多轮迭代推理：

- **思考 (Reasoning)**：分析当前状态，规划下一步行动
- **行动 (Acting)**：调用工具执行具体操作
- **观察 (Observation)**：获取执行结果，更新状态认知
- **迭代优化**：支持多轮循环，直到任务完成

#### 2.2 Browser Use 浏览器自动化

基于 browser-use 实现浏览器自动化操作能力：

- **页面交互**：点击、输入、滚动、拖拽等基础操作
- **跨页面导航**：自动跳转、多标签页管理
- **元素识别**：智能定位页面元素，支持多种选择器
- **状态感知**：实时获取页面状态、DOM 结构

#### 2.3 反思演进机制

实现 Agent 的自我学习与优化能力：

- **失败检测**：识别任务执行失败的情况
- **原因分析**：自动分析失败原因（操作错误、元素变化、逻辑问题等）
- **策略调整**：基于分析结果调整执行策略
- **重试执行**：应用新策略重新执行，直到成功

#### 2.4 多模态视觉理解

支持网页内容和截图的视觉理解：

- **网页内容解析**：提取并理解网页文本、图片、结构
- **截图区域分析**：对用户框选区域进行视觉识别与问答
- **跨模态融合**：结合文本和视觉信息进行综合推理
