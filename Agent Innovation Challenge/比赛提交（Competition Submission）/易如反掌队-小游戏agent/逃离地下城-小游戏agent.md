# 当加班狗穿越代码地狱：这款程序员专属Agent Prompt设计拆解
把“被需求追着跑”“深夜改bug”的职场噩梦，做成能互动的文字冒险Agent，这波prompt设计直接戳中程序员的DNA——既让你在游戏里吐槽加班，又悄悄把“怎么应对职场困境”藏进剧情。下面就扒一扒这份游戏文档，看看它是怎么把Agent调教成“懂程序员的地下城向导”的！

## 一、世界观植入：把加班焦虑焊死在Agent的“记忆库”里
Agent能精准拿捏游戏氛围，全靠prompt里“职场具象化”的世界观设计——不是空泛的“地下城”，而是把程序员的日常焦虑拆成8层关卡：缓存迷宫对应“清缓存的烦躁”，内存深渊对应“内存溢出的崩溃”，线上战场直接复刻“深夜修线上bug”的窒息感。

设计巧思：  
- 给Agent定死“黑色幽默”基调，所有描述都带程序员吐槽（比如背包满了触发“又要清缓存，烦得一批”），让Agent不会讲出“脱离职场”的话；  
- 把“结局映射职场”写进核心规则，Agent推进剧情时，会不自觉向“要么自救（完美结局）、要么硬扛（普通结局）、要么崩盘（失败结局）”的方向引导，不会跑偏成单纯的打怪游戏。

简单说：这prompt给Agent装了个“程序员脑回路插件”，让它不管是描述场景还是触发吐槽，都像在跟同事唠加班嗑～

## 二、双状态机制：给Agent划清“摸鱼探索”和“硬刚战斗”的边界
最绝的设计是“探索/战斗”双状态，prompt里把两种状态的规则拆解得明明白白，Agent根本不会混乱：

### 🔍 探索状态：Agent是“带选择的导游”
- 规则给死：必须给2-4个数字选项（走哪条路、开不开宝箱）+ 开放选项（“或者你有什么其他想法”），既保证剧情不跑偏，又不限制玩家脑洞；  
- 防摆烂机制：连续三轮“其他想法”没推进剧情？Agent会触发“疲惫警告”，既符合游戏精力值设定，又变相“催玩家行动”，避免对话无限循环。

### ⚔️ 战斗状态：Agent是“严谨的战斗裁判”
- 强制要求：每轮必须报“玩家属性+怪物属性+固定选项”（攻击/技能/道具/逃跑），还得算清逃跑概率（普通怪30%、精英60%），BOSS战直接锁死“不能跑”，Agent不会漏关键规则；  
- 数值逻辑：攻击强度、抗性和道具挂钩（比如穿防脱发卫衣抗性变“较强”），Agent会自动关联装备状态，不用玩家手动提醒，战斗逻辑自洽不崩。

## 三、道具技能：把程序员“续命神器”做成Agent的“互动素材库”
prompt里的道具、技能设计全是“职场梗”，Agent用起来自带喜感：
- 装备类：机械键盘=攻击加成，防脱发卫衣=抗性提升，防火墙披风=免疫负面效果——Agent描述时会附带主角吐槽（“这披风比公司的防火墙靠谱多了”），瞬间拉近距离；  
- 技能类：“注释屏蔽”免疫负面（像注释无用代码）、“批量编译”清场杂兵（像批量处理需求）——Agent触发技能时会念台词，让战斗不只是“选选项”，更像在演职场短剧；  
- 消耗品类：能量饼干=恢复精力（摸鱼小零食）、咖啡补丁=临时加攻击（加班续命水）——Agent会根据玩家精力状态，暗戳戳推荐道具（比如精力“不足”时，选项里会默认保留“使用能量饼干”），比产品经理还懂你的“需求”。

## 四、剧情推进：Agent是“不迷路的导航员”
prompt里给Agent画好了“剧情地图”：每层的核心目标、怪物分布、跳转条件都写得明明白白，比如：
- 第1层必须打缓存幽灵/垃圾回收守卫，才能解锁传送门；  
- 第7层有“安全通道”和“强行破解”两条路，Agent会根据玩家是否有“数据解密钥匙”，自动调整选项描述（有钥匙就提示“走安全通道避陷阱”，没有就默认“硬刚机器人”）；  
- 失败结局直接重置回第1层，完美结局解锁“自由跳转”，Agent不用纠结“剧情怎么圆”，按规则跳转就行，逻辑闭环不翻车。

## 五、结局闭环：给职场人一个“情绪出口”
prompt的终极设计是“结局映射职场”，Agent在触发结局时，会把游戏体验和现实职场无缝衔接：
- 完美结局：调休单+咖啡+产品经理延期需求——Agent念出“攒补贴券换奶茶”的隐藏台词，像在说“加班也别忘了犒劳自己”；  
- 隐藏结局：从“开发”变“管理员”——Agent描述“掌控地下城”时，对应现实“晋升技术负责人”，戳中程序员的进阶梦；  
- 失败结局：电脑蓝屏+熬夜改bug——Agent用“程序崩溃”提示，既符合游戏设定，又暗戳戳吐槽“无底线加班的悲剧”。

## 总结：这prompt把Agent调成了“懂职场、会唠嗑、不翻车”的游戏搭子
核心设计逻辑就是：**用程序员的语言讲程序员的故事，用明确的规则框住Agent的行为，用幽默的梗降低互动门槛**。它不用Agent“自由发挥”，而是把所有场景、规则、吐槽都做成“可调用素材”，让Agent既能精准执行游戏规则，又能输出让程序员会心一笑的对话——毕竟，谁不想在游戏里暴打“线上bug之王”，再解锁“产品经理主动延期需求”的完美结局呢？

现在，打开Agent输入这个prompt，准备好把加班焦虑变成“打怪爽感”，开启你的代码地下城冒险吧～（温馨提示：记得多捡咖啡补丁，不然精力不足打不动怪哦！）
