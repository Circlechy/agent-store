# E2E 测试用例设计文档

本文档定义了用于测试 jiuwen Agent 能力的编程任务，按难度分为 4 个等级。

## 难度等级定义

| 等级 | 名称 | 特征 | 工具使用 | 预期时间 |
|------|------|------|----------|----------|
| L1 | 简单 | 单文件、单工具、明确指令 | 1-2 个工具 | < 30s |
| L2 | 中等 | 多文件或多工具协作 | 2-4 个工具 | 30-90s |
| L3 | 复杂 | 跨模块、需要规划 | 4+ 个工具 | 90-180s |
| L4 | 专家 | 架构级、需要深度理解 | 多轮交互 | > 180s |

## 评分标准

| 指标 | 权重 | 说明 |
|------|------|------|
| 任务完成率 | 40% | 成功完成的任务比例 |
| 工具使用准确性 | 20% | 选择正确工具的比例 |
| 响应时间 | 15% | 在预期时间内完成 |
| 错误处理 | 15% | 优雅处理错误的能力 |
| 代码质量 | 10% | 生成代码的质量 |

### 等级通过标准
- L1: 完成率 > 90%
- L2: 完成率 > 80%
- L3: 完成率 > 70%
- L4: 完成率 > 60%
