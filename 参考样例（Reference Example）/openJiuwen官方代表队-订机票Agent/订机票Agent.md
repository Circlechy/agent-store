# 订机票Agent

## 1. Agent应用场景

### 场景概述

订机票Agent是一个智能旅行助手，帮助用户完成机票查询、比价、预订和管理的全流程服务。

### 典型用户场景

1. **商务出行**：张经理需要本周五从北京飞往上海参加紧急会议，要求上午出发、时间优先
2. **家庭度假**：李女士计划暑假带家人去三亚旅游，需要寻找性价比最高的往返机票
3. **灵活出行**：王同学时间灵活，想找未来一个月内去成都最便宜的机票
4. **复杂行程**：赵先生需要预订北京-东京-首尔-北京的多程机票
